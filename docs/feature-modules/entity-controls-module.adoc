== EntityControlsModule

=== General

Supports the creation of ViewElements for any POJO or Entity which can then be used on EntityViews or custom pages.

=== Module dependencies

|===
|Module |Type |Description

|required
|Supports building controls for entities and pojos based on EntityViewElementBatch and the EntityRegistry.
|===
